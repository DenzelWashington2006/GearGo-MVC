# GearGo-MVC

GearGo is a web application for a small equipment-rental business
(camping gear, power tools, event equipment). Customers browse and
request rentals; staff manage equipment and requests; managers
administer the catalogue and users.

## Tech Stack
- C# / ASP.NET Core MVC (.NET)
- Razor views, HTML/CSS
- Git & GitHub (Issues, Pull Requests)

## Running the app
dotnet run --project GearGo
